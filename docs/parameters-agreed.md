## Справочные расчёты (не канон ТЭП, альтернативная методика)

Тетради `notebooks/01–03` считают на собственном пешеходном графе (5 км/ч, шаттл 25 км/ч, без внешних
запросов). Их числа — независимая проверка и диапазон: обеспеченность детсадами до — 17 % пешком /
40–46 % с подвозом (в слайдах — 29 % / 62 %), после +160 мест — 20 % / 48–49 %; эффект шаттла — центр → порт
101 → 23 мин (в слайдах — 90 → 40 мин); в 30 мин от порта 2 % → 17 % жителей. Расхождение — методика
доступности и построения зон; канон для презентации — `reports/metrics_scenarios.md`.

## Шум

Расчётные модели (`reports/metrics_scenarios.md`: 3 070 горожан в зоне ≥ 55 дБА по
`calculate_simplified_noise_frame`; тетрадь 03: 1 058 жителей в нормативных СЗЗ по
СанПиН 2.2.1/2.1.1.1200-03) — это **расчётные оценки, не натурные измерения**. Нормативная рамка —
СанПиН (55 дБА днём для жилой застройки, СЗЗ порт 1 000 м / ж/д 100 м / дорога 50 м).
