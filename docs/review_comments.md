## Правила корректировки is_living (`scripts/process.py`)

1. Дом сопоставлен с Реестром (есть `living_area`) → жилой (1 412).
2. Зона «садоводства, огородничества», ≤ 2 этажей и ≤ 400 м² → нежилой (1 860, из них 104 из реестра).
3. Жилые зоны ФЗ (ИЖС, мало-/средне-/многоэтажная, смешанная), 40–400 м², ≤ 3 этажей → жилой (2 311).
4. «Иные зоны» / вне ФЗ (деревни без детального ФЗ): 40–300 м² и ≥ 2 жилых дома реестра в 150 м → жилой (153).
5. Постройка < 70 м² в 12 м от жилого дома, который в 1,5+ раза больше → хозпостройка, нежилое (190).
6. Теги OSM `building=*` (`data/raw/osm_building_tags.geojson`, 1 520 зданий с типом) — независимая проверка
   вместо ручной сверки по 2ГИС: однозначно нежилой тип (гаражи, сараи, промышленные, теплицы…) → нежилое,
   даже при сопоставлении с реестром (18 зданий, из них 5 гаражей из реестра — ошибка сопоставления по адресу);
   дом по OSM вне садоводства → жилое (1).
7. Ручные правки `data/raw/is_living_overrides.csv` (если появятся).
8. Сезонный фонд: лишние «жилые» дома посёлков сверх переписи → дачи (см. «Новые вопросы»).
9. Остальное → нежилое.

Для новых жилых: `build_floor_area = footprint × этажность`, `living_area = 0,7 × build_floor_area`.

Сверка с OSM по 1 496 зданиям, у которых в OSM указан тип: из 1 087 жилых по OSM (`house`, `apartments`,
`detached`, `residential`) жилыми у нас отмечены 983; остальные 104 — в садоводствах (по правилу курса нежилые).
Из 244 однозначно нежилых по OSM жилыми были 18 — исправлены правилом 6.
