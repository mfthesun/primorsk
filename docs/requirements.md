# Требования курса к слоям (выжимка)

Источники: методички «Этап 1-2 / Этап 3-4. Сбор и обработка городских данных», «Корректировка геослоёв
городских данных в части жилых домов», презентация «26_итог» (Т. Чурякова). Проекция везде **EPSG:4326 (WGS 84)**,
формат **GeoJSON**, имена файлов латиницей с маленькой буквы.

## Этапы 1–2 (максимум 15 баллов)

| Файл | Геометрия | Обязательные атрибуты |
|---|---|---|
| `boundary.geojson` | полигон границы | `name` (str), `population` (int, Росстат 2023/2024) |
| `building.geojson` | полигоны зданий | `build_floor_area` (real) общая площадь; `living_area` (real); `non_living_area` (real); `footprint_area` (real) пятно застройки; `number_of_floors` (int); `population` (int); `is_living` (bool) |
| `blocks.geojson` | кварталы | ручная корректировка: без наложений, «бубликов», скрытой геометрии |
| `landuse.geojson` | функциональное зонирование | названия зон |
| `railways.geojson` | `railway=rail` | — |
| `water.geojson` | водные объекты | — |
| `sea / bay / lake / river.geojson` | отдельные слои | lake: `water=basin,lake,oxbow,pond`; river: `waterway=river,stream`, `water=channel,canal,lock` |
| `roads.geojson` | УДС | `highway_type` (местная/региональная/федеральная), `highway_type_id` (52/51/50) |

Правила для зданий (из замечаний преподавателя группам):
- `is_living`: 0/false — нежилое, 1/true — жилое; проверка по подложке 2ГИС;
- **садоводства — нежилые**;
- площади не могут быть `None` — 0 или вычислить; `build_floor_area` ≥ `footprint_area`;
- `non_living_area = build_floor_area − living_area`;
- `population` — INTEGER; сумма по зданиям = население границы; у нежилых 0.

## Этапы 3–4: сервисы (максимум 60 баллов)

- `[сервис].geojson` — название из таблицы сервисов, с маленькой буквы;
- атрибуты: `service_id` (int, из таблицы; для прочих пусто), `service_name` (str), `capacity` (int, вручную для школ и детских садов);
- геометрия — точка (центроид) или полигон по таблице; **точка должна лежать на полигоне `building.geojson`**
  (кроме остановок, детских/спортивных площадок, вышек связи);
- без пустых геометрий, объектов за границей, дубликатов.

## Сценарий (максимум 15 баллов)

- `boundary.geojson` — граница проектируемой территории;
- `[сервис].geojson` — новые сервисы (правила как выше);
- `landuse.geojson` — новое ФЗ; `roads.geojson` — новые дороги с `highway_type`/`highway_type_id`;
- опционально `blocks`, `building` (атрибуты как в основном слое), `railways`, водные слои;
- должны быть указаны предполагаемое население, вместимость школ и детских садов.

## Презентация (максимум 10 баллов)

7 минут: справка о территории, здания (жилые/нежилые, этажность), карты по каждой инфраструктуре с легендой,
слой кварталов, выводы.
